# نصب دانلودر یوتیوب در Render

این پروژه یک کادر فارسی مستقل است: می‌توانید آدرس سرویس Render را در iframe وردپرس قرار دهید. استخراج کیفیت‌ها با `yt-dlp` انجام می‌شود و Docker زمان ساخت `Deno` و `ffmpeg` را هم نصب می‌کند.

1. در GitHub یک Repository جدید بسازید (مثلاً `youtube-quality-viewer`).
2. فایل‌های **داخل ZIP** را از حالت فشرده خارج کنید و با گزینه **Add file > Upload files** به ریشه مخزن GitHub آپلود کنید. **خود فایل ZIP را به‌تنهایی آپلود نکنید.** فایل `Dockerfile` باید در ریشه مخزن باشد.
3. در Render به **New > Web Service** بروید، حساب GitHub را متصل و مخزن را انتخاب کنید.
4. در قسمت **Language / Runtime** گزینه **Docker** و در قسمت **Instance Type** گزینه **Free** را انتخاب و **Create Web Service** را بزنید.
5. پس از **Live** شدن سرویس، آدرس `https://NAME.onrender.com` را باز کنید.
6. در وردپرس بلوک «HTML سفارشی» بگذارید و کد زیر را با آدرس واقعی Render جایگزین کنید:

```html
<iframe src="https://NAME.onrender.com/" width="100%" height="700" style="border:0;border-radius:15px" loading="lazy" title="دانلودر یوتیوب"></iframe>
```

## محدودیت‌ها
- Render رایگان ممکن است پس از ۱۵ دقیقه بی‌کاری بخوابد؛ بار اول باز شدن طول می‌کشد.
- امکان دارد IP سرویس‌های ابری از سمت YouTube محدود شود؛ بنابراین کارکرد برای همه ویدیوها تضمین‌شده نیست.
- کیفیت‌های تصویر بدون صدا به صورت جدا نشان داده می‌شوند. این نسخه ادغام صدا و تصویر و پروکسی کردن حجم زیاد ویدیو را انجام نمی‌دهد.
- لینک‌های خروجی موقت‌اند و گاهی در مرورگر کاربر به دلیل تفاوت IP/هدر کار نمی‌کنند.
- سرویس رایگان برای ترافیک بالا مناسب نیست؛ طبق شرایط Render ممکن است محدودیت یا هزینه پهنای باند وجود داشته باشد.
- فقط برای محتوایی استفاده کنید که اجازه دریافت آن را دارید.

برای مشاهده خطاهای واقعی برنامه: Render > سرویس > Logs. در صورت شکست ساخت، بخش Logs را ببینید.
